# Security Policy

## Scope

This repository focuses on frontier AI risk governance research.

It does not contain:
- model weights;
- private evaluation datasets;
- operational instructions for harmful activities.

## Reporting Issues

If you identify a security issue affecting the repository infrastructure, code, automation or data integrity, please report it privately before public disclosure.

Include:

- description of the issue;
- affected component;
- reproduction steps if applicable;
- potential impact.

## Research Integrity Issues

Issues related to:

- incorrect evidence records;
- unsupported claims;
- source attribution;
- evaluation interpretation;

should be reported as research integrity issues.

## Responsible Disclosure

Please allow reasonable time for review before public disclosure of security-related problems.
