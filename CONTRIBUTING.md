# Contributing Guidelines

Thank you for contributing to the Frontier Model Risk Trigger Map.

This project aims to maintain a reproducible evidence-to-governance pipeline for frontier AI risk research.

## Contribution Principles

Contributions should:

- use publicly verifiable sources;
- distinguish provider disclosures from independent evaluations;
- record uncertainty and limitations;
- avoid unsupported claims or speculation;
- preserve reproducibility.

## Adding New Evidence

Before adding an evidence record, contributors should verify:

1. The model identity and version are clearly specified.
2. The source is publicly accessible.
3. The evaluation methodology is documented.
4. The evaluator access conditions are recorded.
5. Limitations and uncertainty are explicitly noted.

## Source Quality

Preferred sources include:

- official system cards and model cards;
- independent evaluation reports;
- regulatory publications;
- academic or research organization reports.

## Evidence Standards

The project does not use a universal risk score.

Evidence should be interpreted through:

Evidence  
→ Evaluation  
→ Trigger  
→ Governance Action

Different providers and evaluators may use different thresholds. Comparisons must therefore include methodological caveats.

## Review Process

Changes affecting:

- model records;
- evidence datasets;
- evaluation registries;
- trigger logic;
- governance decisions;

should be reviewed before merging.

## Research Integrity

Contributors should disclose:

- conflicts of interest;
- evaluator limitations;
- missing information;
- uncertainty in interpretation.
