# Contributing

Contributions are welcome when they improve traceability, coverage or methodology.

## Evidence contribution checklist

- Use a primary source or a clearly identified independent evaluation.
- Add the source to `data/sources/sources.csv` before referencing it.
- Write one narrow claim per evidence row.
- Preserve the original unit and framework terminology.
- Record missing information as missing; do not estimate unpublished values.
- Explain evaluator independence, access and configuration limits.
- Include both concerning and reassuring findings where material.
- Do not add dangerous operational details or private information.
- Run `make validate`, `make build` and `make test`.

High-impact changes to decision rules should include a written rationale and receive review from at least one other contributor.
