# Frontier Model Risk Trigger Map — Research Note

## Purpose

This note describes the evidence-to-governance methodology of the project.

The repository does not produce a universal risk score.

It provides a structured pipeline:

Evidence  
→ Evaluation  
→ Trigger  
→ Governance Action

## Methodological Principles

- Separate provider disclosures from independent evaluations.
- Track uncertainty explicitly.
- Record limitations of evaluation access.
- Avoid unsupported cross-model rankings.
- Preserve reproducibility of evidence decisions.

## Current Scope

The project includes:

- model registry;
- source registry;
- evidence dataset;
- evaluation registry;
- confidence assessment;
- trigger map;
- decision framework;
- governance reporting.
