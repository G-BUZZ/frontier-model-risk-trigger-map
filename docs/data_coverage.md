# Evidence Coverage Status

The repository tracks not only frontier model identity and available sources, but also the current level of evidence coverage.

## Coverage levels

### High
Multiple evidence sources are available, including independent evaluations where possible.

### Medium
Public provider documentation and partial independent evidence are available.

### Low
Limited public evidence exists or only preliminary information is available.

### Pending
The model is registered but evidence extraction or evaluation analysis is not yet complete.

Coverage status describes the state of available public evidence. It does not represent model safety or capability ranking.
