This directory contains applied examples of the evidence-to-governance workflow.

## Methodological Principle

Case studies do not classify models as safe or unsafe.

They demonstrate a process:

Evidence  
→ Interpretation  
→ Confidence assessment  
→ Trigger condition  
→ Possible governance action

All conclusions remain limited by available public information.
