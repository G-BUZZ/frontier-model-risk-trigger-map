# Evidence Confidence Framework

## Purpose

This framework describes how evidence quality is assessed.

The Frontier Model Risk Trigger Map does not treat all evidence as equivalent.

Confidence depends on:

- source independence;
- evaluation methodology;
- evaluator access;
- reproducibility;
- deployment relevance.

---

## Confidence Dimensions

| Dimension | Description |
|---|---|
| Source independence | Provider disclosure, independent evaluation, regulator source |
| Method transparency | Availability of methodology and test conditions |
| Access level | Black-box, controlled access, white-box |
| Reproducibility | Ability to reproduce findings |
| Deployment relevance | Similarity between evaluation and real deployment |

---

## Confidence Levels

### High confidence

Multiple independent sources or transparent evaluations with strong methodological detail.

### Medium confidence

Useful evidence with limitations in access, methodology or independence.

### Low confidence

Preliminary signals, incomplete information or limited verification.

---

## Limitations

Evidence confidence is not a risk score.

A high-confidence observation may indicate either increased capability or effective safeguards.

The purpose is to improve interpretation, not rank models.
