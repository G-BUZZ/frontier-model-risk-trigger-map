# Evaluation Registry

## Purpose

The evaluation registry records how frontier model evidence was produced.

Evidence records describe individual findings.
Evaluation records describe the assessment process behind those findings.

## Fields

| Field | Meaning |
|---|---|
| evaluator | Organization performing the evaluation |
| evaluator_type | Developer, independent evaluator, government research |
| methodology | Evaluation approach |
| model_access | Level of access available during testing |
| independence_level | Degree of separation from model developer |
| limitations | Known weaknesses or uncertainty |

## Independence Levels

### Low
Provider-conducted evaluation.

### Medium
External evaluator with limited independence or special access conditions.

### High
Independent replication without provider control.

## Current Limitations

The registry currently contains mostly provider disclosures.
Future versions should prioritize independent evaluations and regulatory assessments.
