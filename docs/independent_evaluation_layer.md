# Independent Evaluation Layer

## Purpose

This dataset separates external evaluations from provider disclosures.

Provider system cards are valuable sources of information, but they may use:
- proprietary benchmarks;
- internal thresholds;
- limited disclosure of methodology.

Independent evaluations provide additional evidence by introducing separation
between model developers and evaluators.

## Independence Levels

| Level | Description |
|---|---|
| Low | Provider-controlled evaluation |
| Medium | External evaluator with limited access conditions |
| High | Independent replication without provider control |

## Current Limitations

The current registry contains limited independent evaluations.

Important missing areas:
- independent cyber replication;
- independent biological capability evaluation;
- independent agentic behaviour testing;
- regulatory assessments.

## Principle

Absence of independent evidence should be treated as uncertainty, not as
evidence of safety.
